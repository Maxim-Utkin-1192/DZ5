# Отчёт о разработке — ДЗ4

## Frontend-приложение с AI-агентом (Rick and Morty Portal)

### 🎯 Цель проекта

Разработать Frontend-приложение для просмотра и управления персонажами вселенной Rick and Morty с использованием AI-агента для генерации кода.

### 🛠 Технологический стек

- React 18 — UI-фреймворк
- Vite 4 — сборщик и dev-сервер
- React Router 6 — маршрутизация
- Tailwind CSS 3 — стилизация
- Supabase JS — клиент для работы с backend
- Rick and Morty API — внешний источник данных

### 🤖 Использование AI-агента

В процессе разработки использовался AI-агент (DeepSeek / ChatGPT) для:

#### 1. Инициализация проекта

Промпт:
«Создай структуру React-проекта: Vite + React 18, React Router 6, Tailwind CSS 3, Supabase Client. Структура папок: components/, pages/, hooks/, api/, context/, utils/. Настрой vite.config.js, tailwind.config.js. Создай .env.example.»

Результат: готовая структура проекта с конфигами.

#### 2. Генерация компонентов

Промпт:
«Создай React-компонент CharacterCard, который принимает объект персонажа и отображает: изображение, имя, статус (с цветом), вид, происхождение, локацию. Добавь кнопку "Подробнее" и кнопку "В избранное".»

Результат: src/components/CharacterCard.jsx.

#### 3. Реализация страниц

Промпт:
«Создай страницу CharactersPage: загрузка персонажей из Rick and Morty API, поиск по имени, пагинация, интеграция с Supabase для избранного.»

Результат: src/pages/CharactersPage.jsx.

#### 4. Отладка

Промпт:
«Ошибка: crypto$2.getRandomValues is not a function в Vitest на Node.js 16. Как исправить?»

Результат: обсудили варианты — полифилл, смена версии Vitest, браузерный режим.

### 🐛 Проблемы и решения

| Проблема | Решение |
|----------|---------|
| CORS при запросах к API | Использование официального API с поддержкой CORS |
| Rate limit Supabase | Создание пользователей через Dashboard |
| crypto.getRandomValues в Vitest | Тесты на чистом JavaScript (tests.html) |
| Ошибка "Email not confirmed" | Отключение подтверждения email в Supabase |
| Ошибка 404 при поиске | Разделение "не найдено" и "ошибка сети" |

### 💡 Выводы

1. AI-агент значительно ускоряет разработку — генерация кода компонентов занимает секунды.
2. Отладка через AI эффективна — быстрый поиск причин ошибок.
3. Важно проверять сгенерированный код — иногда AI предлагает устаревшие решения.
4. Тесты на чистом JS — рабочая альтернатива для ограниченных сред (Windows 8.1).
